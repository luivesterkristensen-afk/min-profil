Om projektet

Dette projekt er en skoleopgave, hvor jeg lærer at bruge Git gennem terminalen i VS Code med PowerShell.

Jeg har tidligere brugt Git gennem VS Code og GitHub Desktop, men formålet er nu at lære kommandoerne og forstå, hvordan Git fungerer.

Hvad jeg lærer

At navigere mellem mapper i terminalen.

At oprette og arbejde med Git-repositories.

At tilføje filer og lave commits.

At se historikken over commits.

At arbejde med branches.

At forbinde et lokalt repository til GitHub.

At bruge push og pull til at synkronisere ændringer.

Teknologier

Git

GitHub

Visual Studio Code

PowerShell

Formål

At blive mere selvstændig i brugen af Git og kunne arbejde med versionsstyring direkte fra terminalen uden at være afhængig af grafiske værktøjer.
